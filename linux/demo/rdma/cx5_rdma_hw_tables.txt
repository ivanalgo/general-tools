ConnectX-5 RDMA 硬件资源表全景大图
====================================

说明：
  1. 本图只画 ConnectX-5 硬件可见/使用的资源表，以及这些表指向的主机内存表格。
  2. 不画 ibverbs、libmlx5、mlx5_core、rdma_cm 等软件对象。
  3. 表格式统一为：首项 + [...] + 末项。
  4. 字段如果指向另一张表，从字段位置直接用箭头画到目标表头。

图例：
  [NIC]   = CX5 NIC 硬件侧：硬件上下文表/片上资源/ICM context
  [DRAM]  = 主机 CPU DRAM 侧：WQE/CQE/EQE/MTT/KLM/DBR/数据页
  [BAR]   = PCIe BAR 映射区域：UAR/BlueFlame/Doorbell MMIO
  ----->  = 表项字段引用另一张硬件表或 DRAM 表
  =====>  = 数据/完成/事件流向

====================================================================================================
                         ONE RC QP DATA PATH: SEND / WRITE / READ RESOURCE CHAIN
====================================================================================================

CPU posts WQE into DRAM SQ/RQ and rings BAR doorbell:

  [BAR] UAR / BlueFlame
      |
      | doorbell MMIO
      v
  [NIC] QPC Table
      |-- sq_wq_ptr -------------------------------> [DRAM] SQ WQE Ring Table
      |                                                 |
      |                                                 | lkey
      |                                                 v
      |                                             [NIC] MPT/MKey Table
      |                                                 |
      |                                                 | translation_ptr
      |                                                 v
      |                                             [DRAM] MTT/KLM Table
      |                                                 |
      |                                                 | dma_pa
      |                                                 v
      |                                             [DRAM] User Registered Memory Pages
      |
      |-- rq_wq_ptr -------------------------------> [DRAM] RQ WQE Ring Table
      |                                                 |
      |                                                 | lkey
      |                                                 v
      |                                             [NIC] MPT/MKey Table
      |
      |-- send_cqn / recv_cqn ---------------------> [NIC] CQC Table
      |                                                 |
      |                                                 | cqe_buf_ptr
      |                                                 v
      |                                             [DRAM] CQE Ring Table
      |                                                 |
      |                                                 | eqn when CQ event is generated
      |                                                 v
      |                                             [NIC] EQC Table
      |                                                 |
      |                                                 | eqe_buf_ptr
      |                                                 v
      |                                             [DRAM] EQE Ring Table
      |
      |-- pdn --------------------------------------> [NIC] PD Table
      |
      |-- tisn -------------------------------------> [NIC] TIS Table
      |
      |-- sq/rq_dbr_ptr ----------------------------> [DRAM] Doorbell Record Table


RDMA WRITE / RDMA READ remote memory authorization path:

  Local [DRAM] SQ_WQE
      |
      | contains remote_addr + rkey
      v
  Packet on wire
      |
      | arrives at remote CX5 NIC
      v
  Remote [NIC] QPC Table
      |
      | checks QP state, transport, PSN, remote_qpn, path, access permissions
      v
  Remote [NIC] MPT/MKey Table
      |
      | lookup by rkey; checks pdn/access/iova/length
      v
  Remote [DRAM] MTT/KLM Table
      |
      | translates virtual/io address to DMA physical pages
      v
  Remote [DRAM] User Registered Memory Pages
