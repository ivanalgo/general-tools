ConnectX-5 RDMA Hardware Resource Tables
====================================

This file is intended for direct reading on GitHub. Use a monospace font.

Scope:
  - Only CX5 NIC-side hardware context tables and host DRAM tables referenced by them are shown.
  - Software objects such as ibverbs, libmlx5, mlx5_core, and rdma_cm are not shown.

Drawing convention:
  - Each table is drawn as: entry[0] -> [...] -> entry[N].
  - Fields that reference other tables/resources exit directly from the box border; no internal crossing lines.
  - Form:

        target table/resource (field_name)   <---| | - field_name

    That is, the target table/resource is written on the same field row; no folded lines below the table.

Legend:
  [NIC]   CX5 NIC side: hardware context tables / ICM context / on-device resources
  [DRAM]  Host CPU DRAM side: WQE/CQE/EQE/MTT/KLM/DBR/user pages
  [BAR]   PCIe BAR mapped area: UAR / BlueFlame / Doorbell MMIO
  <---|   Direct reference from a box border to the target text
  --->    Association from a left-side NIC table to a right-side DRAM table/resource
  ===>    Data flow / doorbell / packet / completion / event

====================================================================================================
                         15. Hardware Resource Chain for RC QP SEND / WRITE / READ
====================================================================================================

CPU writes WQE in DRAM and rings BAR doorbell. Hardware-side tables are on the left; related DRAM resources are on the right:

  +-------------------------------+                         +--------------------------------------+
  | [BAR] UAR / BlueFlame         | === doorbell/MMIO ===>  | [NIC] QPC / SQ scheduler             |
  +-------------------------------+                         +--------------------------------------+

  +--------------------------------------+                  +-----------------------------------------------+
  | [NIC] QPC Table                      | -- sq_wq_ptr --> | [DRAM] SQ WQE Ring Table                       |
  |  - qpn / transport / state           | -- rq_wq_ptr --> | [DRAM] RQ WQE Ring Table                       |
  |  - sq_dbr_ptr / rq_dbr_ptr           | ---------------> | [DRAM] Doorbell Record Table                   |
  |                                      |                  |                                               |
  |  NIC-side references:                |                  |                                               |
  |    pdn       -> [NIC] PD Table       |                  |                                               |
  |    send_cqn  -> [NIC] CQC Table      |                  |                                               |
  |    recv_cqn  -> [NIC] CQC Table      |                  |                                               |
  |    tisn      -> [NIC] TIS Table      |                  |                                               |
  +--------------------------------------+                  +-----------------------------------------------+

  +--------------------------------------+                  +-----------------------------------------------+
  | [NIC] CQC Table                      | -- cqe_buf_ptr ->| [DRAM] CQE Ring Table                          |
  |  - cq_dbr_ptr                        | ---------------> | [DRAM] Doorbell Record Table                   |
  |                                      |                  |                                               |
  |  NIC-side reference:                 |                  |                                               |
  |    eqn -> [NIC] EQC Table            |                  |                                               |
  +--------------------------------------+                  +-----------------------------------------------+

  +--------------------------------------+                  +-----------------------------------------------+
  | [NIC] EQC Table                      | -- eqe_buf_ptr ->| [DRAM] EQE Ring Table                          |
  |  - eq_dbr_ptr                        | ---------------> | [DRAM] Doorbell Record Table                   |
  +--------------------------------------+                  +-----------------------------------------------+

  +--------------------------------------+                  +-----------------------------------------------+
  | [NIC] MPT/MKey Table                 | -- translation ->| [DRAM] MTT/KLM Table                           |
  |  - pdn -> [NIC] PD Table             |                  |  - dma_pa/page_pa --> User Registered Pages    |
  +--------------------------------------+                  +-----------------------------------------------+

RDMA WRITE / RDMA READ remote memory authorization path:

  Local side:                                                Remote side:
  +--------------------------------------+                  +-----------------------------------------------+
  | [DRAM] SQ_WQE                        | === packet ===>  | [NIC] QPC Table                                |
  |  - remote_addr / rkey                |                  |  checks QP state / transport / PSN / path      |
  +--------------------------------------+                  +-----------------------------------------------+
                                                                    |
                                                                    v
                                                            +-----------------------------------------------+
                                                            | [NIC] MPT/MKey Table                           |
                                                            |  checks rkey / PD / access / iova / length     |
                                                            +-----------------------------------------------+
                                                                    |
                                                                    v
                                                            +-----------------------------------------------+
                                                            | [DRAM] MTT/KLM -> User Memory Pages            |
                                                            +-----------------------------------------------+
