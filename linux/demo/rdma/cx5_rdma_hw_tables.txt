ConnectX-5 RDMA 硬件资源表全景大图
====================================

目标：
  1. 只画 ConnectX-5 硬件可见/使用的资源表，以及硬件上下文指向的主机侧内存表。
  2. 不画 ibverbs、libmlx5、mlx5_core、rdma_cm 等软件对象。
  3. 每张表均使用“首项 + [...] + 末项”：entry[0] -> [...] -> entry[N]。
  4. 如果 field 指向另一张表，统一从 field 左边引出线：

        |<-- field_name
        |
        +-----> Target Table

     即：左出线，然后下折；必要时再左折/右折，最后写目标表名。

图例：
  [NIC]   = CX5 NIC 硬件侧：硬件上下文表/ICM context/片上硬件资源
  [DRAM]  = 主机 CPU DRAM 侧：WQE/CQE/EQE/MTT/KLM/DBR/数据页
  [BAR]   = PCIe BAR 映射区域：UAR/BlueFlame/Doorbell MMIO
  <------ = 从 field 左边引出的引用线
  +-----> = 折线后指向目标表
  =====>  = 数据/完成/事件流向

====================================================================================================
                         ONE RC QP DATA PATH: SEND / WRITE / READ RESOURCE CHAIN
====================================================================================================

CPU posts WQE into DRAM SQ/RQ and rings BAR doorbell:

  [BAR] UAR / BlueFlame
      |
      | doorbell MMIO
      v
  [NIC] QPC Table
      |<-- sq_wq_ptr
      |
      +-----> [DRAM] SQ WQE Ring Table
      |           |<-- lkey
      |           |
      |           +-----> [NIC] MPT/MKey Table
      |                       |<-- translation_ptr
      |                       |
      |                       +-----> [DRAM] MTT/KLM Table
      |                                   |<-- dma_pa
      |                                   |
      |                                   +-----> [DRAM] User Registered Memory Pages
      |
      |<-- rq_wq_ptr
      |
      +-----> [DRAM] RQ WQE Ring Table
      |           |<-- lkey
      |           |
      |           +-----> [NIC] MPT/MKey Table
      |
      |<-- send_cqn / recv_cqn
      |
      +-----> [NIC] CQC Table
      |           |<-- cqe_buf_ptr
      |           |
      |           +-----> [DRAM] CQE Ring Table
      |           |
      |           |<-- eqn
      |           |
      |           +-----> [NIC] EQC Table
      |                       |<-- eqe_buf_ptr
      |                       |
      |                       +-----> [DRAM] EQE Ring Table
      |
      |<-- pdn
      |
      +-----> [NIC] PD Table
      |
      |<-- tisn
      |
      +-----> [NIC] TIS Table
      |
      |<-- sq/rq_dbr_ptr
      |
      +-----> [DRAM] Doorbell Record Table


RDMA WRITE / RDMA READ remote memory authorization path:

  Local [DRAM] SQ_WQE
      |<-- remote_addr / rkey
      |
      +====> Packet on wire
                 |
                 | arrives at remote CX5 NIC
                 v
             Remote [NIC] QPC Table
                 |
                 | checks QP state, transport, PSN, remote_qpn, path, access permissions
                 v
             Remote [NIC] MPT/MKey Table
                 |<-- rkey lookup
                 |
                 +-----> checks pdn/access/iova/length
                 |
                 |<-- translation_ptr
                 |
                 +-----> Remote [DRAM] MTT/KLM Table
                             |<-- dma_pa/page_pa
                             |
                             +-----> Remote [DRAM] User Registered Memory Pages
