ConnectX-5 RDMA 硬件资源表全景大图
====================================

本文件用于放到 GitHub 直接打开阅读。建议使用等宽字体查看。

范围：
  - 只画 CX5 NIC 硬件侧上下文表，以及硬件上下文指向的主机 DRAM 表。
  - 不画 ibverbs、libmlx5、mlx5_core、rdma_cm 等软件对象。

画法约定：
  - 每张表都画成：entry[0] -> [...] -> entry[N]。
  - 指向其它表/资源的 field，不在表内部横向穿线；统一从“框图左边界”直接出线。
  - 形式如下：

        target table/resource (field_name)   <---| | - field_name

    即：field 所在行从表格左边界拉出，左侧直接写它关联到的目标表/资源；不再在表格下方画折线。

图例：
  [NIC]   CX5 NIC 硬件侧：硬件上下文表 / ICM context / 片上硬件资源
  [DRAM]  主机 CPU DRAM 侧：WQE/CQE/EQE/MTT/KLM/DBR/用户数据页
  [BAR]   PCIe BAR 映射区域：UAR / BlueFlame / Doorbell MMIO
  <---|   从框图左边界直接引出到左侧目标说明
  --->    NIC 左侧硬件表到右侧 DRAM 表/资源的关联箭头
  ===>    数据流 / doorbell / packet / completion / event

                                      0. 表位置总览
====================================================================================================

  NIC / BAR 硬件侧表放左边，主机 DRAM 侧表放右边；箭头表示硬件上下文里的指针/编号关联。

  +--------------------------------------+          +-----------------------------------------------+
  | [NIC] CX5 硬件侧上下文表             |          | [DRAM] 主机 CPU 内存侧表                       |
  |--------------------------------------|          |-----------------------------------------------|
  | QPC Table                            | --+----> | SQ WQE Ring                                   |
  |  - sq_wq_ptr / rq_wq_ptr             |   +----> | RQ WQE Ring                                   |
  |  - sq_dbr_ptr / rq_dbr_ptr           |   +----> | Doorbell Record Table                         |
  |                                      |          |                                               |
  | CQC Table                            | --+----> | CQE Ring                                      |
  |  - cqe_buf_ptr / cq_dbr_ptr          |   +----> | Doorbell Record Table                         |
  |                                      |          |                                               |
  | EQC Table                            | --+----> | EQE Ring                                      |
  |  - eqe_buf_ptr / eq_dbr_ptr          |   +----> | Doorbell Record Table                         |
  |                                      |          |                                               |
  | MPT/MKey Table                       | -------> | MTT/KLM Table                                 |
  |  - translation_ptr                   |          | User Registered Memory Pages                  |
  |                                      |          |                                               |
  | PD Table / TIS Table                 |          |                                               |
  +--------------------------------------+          +-----------------------------------------------+

  +--------------------------------------+
  | [BAR] PCIe BAR 映射区域              |
  |--------------------------------------|
  | UAR Page                             |
  | BlueFlame Area                       |
  | Doorbell MMIO Registers              |
  +--------------------------------------+

====================================================================================================
                         15. 一条 RC QP 的 SEND / WRITE / READ 硬件资源链
====================================================================================================

CPU writes WQE in DRAM and rings BAR doorbell. 硬件侧表放左边，关联的 DRAM 表/资源放右边：

  +-------------------------------+                         +--------------------------------------+
  | [BAR] UAR / BlueFlame         | === doorbell/MMIO ===>  | [NIC] QPC / SQ scheduler             |
  +-------------------------------+                         +--------------------------------------+

  +--------------------------------------+                  +-----------------------------------------------+
  | [NIC] QPC Table                      | -- sq_wq_ptr --> | [DRAM] SQ WQE Ring Table                       |
  |  - qpn / transport / state           | -- rq_wq_ptr --> | [DRAM] RQ WQE Ring Table                       |
  |  - sq_dbr_ptr / rq_dbr_ptr           | ---------------> | [DRAM] Doorbell Record Table                   |
  |                                      |                  |                                               |
  |  NIC-side references:                |                  |                                               |
  |    pdn       -> [NIC] PD Table       |                  |                                               |
  |    send_cqn  -> [NIC] CQC Table      |                  |                                               |
  |    recv_cqn  -> [NIC] CQC Table      |                  |                                               |
  |    tisn      -> [NIC] TIS Table      |                  |                                               |
  +--------------------------------------+                  +-----------------------------------------------+

  +--------------------------------------+                  +-----------------------------------------------+
  | [NIC] CQC Table                      | -- cqe_buf_ptr ->| [DRAM] CQE Ring Table                          |
  |  - cq_dbr_ptr                        | ---------------> | [DRAM] Doorbell Record Table                   |
  |                                      |                  |                                               |
  |  NIC-side reference:                 |                  |                                               |
  |    eqn -> [NIC] EQC Table            |                  |                                               |
  +--------------------------------------+                  +-----------------------------------------------+

  +--------------------------------------+                  +-----------------------------------------------+
  | [NIC] EQC Table                      | -- eqe_buf_ptr ->| [DRAM] EQE Ring Table                          |
  |  - eq_dbr_ptr                        | ---------------> | [DRAM] Doorbell Record Table                   |
  +--------------------------------------+                  +-----------------------------------------------+

  +--------------------------------------+                  +-----------------------------------------------+
  | [NIC] MPT/MKey Table                 | -- translation ->| [DRAM] MTT/KLM Table                           |
  |  - pdn -> [NIC] PD Table             |                  |  - dma_pa/page_pa --> User Registered Pages    |
  +--------------------------------------+                  +-----------------------------------------------+

RDMA WRITE / RDMA READ remote memory authorization path:

  Local side:                                                Remote side:
  +--------------------------------------+                  +-----------------------------------------------+
  | [DRAM] SQ_WQE                        | === packet ===>  | [NIC] QPC Table                                |
  |  - remote_addr / rkey                |                  |  checks QP state / transport / PSN / path      |
  +--------------------------------------+                  +-----------------------------------------------+
                                                                    |
                                                                    v
                                                            +-----------------------------------------------+
                                                            | [NIC] MPT/MKey Table                           |
                                                            |  checks rkey / PD / access / iova / length     |
                                                            +-----------------------------------------------+
                                                                    |
                                                                    v
                                                            +-----------------------------------------------+
                                                            | [DRAM] MTT/KLM -> User Memory Pages            |
                                                            +-----------------------------------------------+
